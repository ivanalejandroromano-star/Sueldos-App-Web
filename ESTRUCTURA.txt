# 📁 Estructura de Carpeta Github

Carpeta lista para GitHub con todos los archivos necesarios.

## Archivos de Documentación

- **README.md** — Descripción del proyecto, features, API endpoints
- **INSTALACION.md** — Guía paso-a-paso de instalación (solución de problemas incluida)
- **INICIO_RAPIDO.md** — Cómo subir a GitHub en 3 pasos
- **CLAUDE.md** — Documentación técnica para desarrolladores (arquitectura, fórmulas, etc.)

## Scripts de Setup

- **setup.sh** — Instalación automática (Linux/Mac)
  - Crea venv, instala dependencias, crea .env
  - Ejecutar: `chmod +x setup.sh && ./setup.sh`

- **setup.bat** — Instalación automática (Windows)
  - Haz doble click o ejecuta en CMD
  - Mismo resultado que setup.sh

## Configuración

- **requirements.txt** — Dependencias Python (Flask, pdfplumber, reportlab, openpyxl, etc.)
- **.env.example** — Plantilla de variables de entorno
- **.gitignore** — Qué NO subir a GitHub (venv, *.db, __pycache__, etc.)

## Código

- **backend/app.py** — Servidor Flask completo (~1000 líneas)
  - 30+ endpoints
  - CRUD de empleados, deudas, pasajes, retroactivos
  - Cierre de quincena con lógica de deudas
  - Generación de PDFs y Excel

- **frontend/index.html** — Aplicación SPA completa (~2500 líneas)
  - Alpine.js para reactividad
  - 6 vistas: Quincena, Empleados, Deudas, Pasajes, Retroactivos, Historial
  - Modal dialogs para CRUD
  - Tablas con filtros

- **frontend/logo.png** — Logo de la empresa

## Cómo usar

1. Descarga/clona esta carpeta
2. Si tienes setup.sh/setup.bat: ejecuta
3. Si instalas manualmente: crea venv, `pip install -r requirements.txt`
4. Abre 2 terminales:
   - Terminal 1: `python backend/app.py`
   - Terminal 2: `cd frontend && python3 -m http.server 8000`
5. Abre navegador: `http://localhost:8000`
