# 💼 Sueldos App - Sistema de Gestión de Nómina

Aplicación web para gestionar nómina, deudas, retroactivos y más.

**Completamente gratuita. Sin servidores. 100% en la nube.**

---

## 🚀 Deploy en Vercel (1 Click)

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/ivanalejandroromano-star/Sueldos-App-Web)

**Instrucciones:**
1. Haz click en el botón de arriba
2. GitHub te pedirá permiso → Autoriza
3. Vercel detectará la app automáticamente
4. Click en "Deploy"
5. ¡Listo! Tu app está en vivo en 1 minuto

**Tu URL será algo como:** `https://sueldos-app-XXXXX.vercel.app`

---

## 📊 Características

✅ Gestión de Empleados  
✅ Cálculo de Quincenas  
✅ Sistema de Deudas con Cuotas  
✅ Retroactivos distribuidos en múltiples quincenas  
✅ Pasajes y descuentos  
✅ Generación de PDFs  
✅ Exportación a Excel  
✅ **100% accesible desde cualquier dispositivo**  
✅ **Sin servidor de tu PC prendido**

---

## 🛠️ Tecnología

- **Frontend:** HTML5 + Alpine.js + Tailwind CSS
- **BD:** SQLite (en el navegador con sql.js)
- **Hosting:** Vercel (gratis)

---

## 📱 Acceso

Una vez deployado en Vercel, puedes acceder desde:
- 💻 Desktop
- 📱 Celular (responsive)
- 🌍 Cualquier lugar con internet

Sin necesidad de servidor prendido.

---

## 📝 Notas

- Los datos se guardan en tu navegador (IndexedDB)
- Los cambios persisten entre sesiones
- Puedes compartir el link con otros usuarios
- Todo funciona offline (excepto la carga inicial)
