🚀 OPCIÓN 1: QUIERO USARLO LOCALMENTE AHORA

1. Estoy en la carpeta Github/

2. Si tienes Linux/Mac:
   $ chmod +x setup.sh
   $ ./setup.sh

3. Si tienes Windows:
   > Haz doble click en setup.bat

4. Abre 2 terminales:

   TERMINAL 1:
   $ source venv/bin/activate     (Linux/Mac)
   $ python backend/app.py

   TERMINAL 2:
   $ cd frontend
   $ python3 -m http.server 8000

5. Abre navegador:
   http://localhost:8000

✨ FEATURES DEL SISTEMA:

✅ 6 Vistas Principales
   - 📊 Quincena: Cálculo de nómina quincenal
   - 👥 Empleados: ABM de personal
   - 💰 Deudas: Gestión de descuentos con cuotas
   - 🚕 Pasajes: Control de gastos de viaje
   - 📆 Retroactivos: Back-pay en múltiples quincenas
   - 📈 Historial: Consulta de períodos anteriores

✅ Funcionalidades
   - Cálculos automáticos: Bruto, Recibos, Deudas
   - Importar PDFs del banco
   - Generar PDFs: Recibo B + Cinta Billete
   - Exportar a Excel
   - Cierre de quincena (aplica deudas automáticamente)
   - Reapertura de quincena (para editar)
   - Sistema multi-obra (BD aislada por proyecto)

✅ Tecnología
   - Frontend: HTML + Alpine.js (sin build step)
   - Backend: Flask + SQLite
   - Responsive: Funciona en desktop y tablet
   - CORS habilitado (desarrollo y producción)

❓ PROBLEMAS COMUNES:

P: ¿Qué Python necesito?
R: Python 3.8 o superior. Descárgalo de python.org

P: ¿Necesito Node.js?
R: NO. Solo Python. El frontend es HTML puro.

P: ¿Cómo cambio el puerto?
R: Ve a INSTALACION.md → "¿Quieres cambiar el puerto?"

P: ¿Qué pasa si no ejecuto setup?
R: Necesitarás crear venv manualmente:
   $ python3 -m venv venv
   $ source venv/bin/activate
   $ pip install -r requirements.txt

P: ¿Se suben los datos (BD) a GitHub?
R: NO. El .gitignore excluye *.db. Los datos quedan locales.

P: ¿Funciona en Heroku/AWS/Docker?
R: Sí, pero con cambios. Ver CLAUDE.md → "Despliegue en Producción"
